📌 كيف تحصل على APK يعمل على الهاتف؟

الطريقة 1 — GitHub Actions (الأسرع 5 دق):
1. ارفع ZIP على GitHub → Actions تشغل تلقائياً
2. انتظر → نزّل APK من Artifacts

الطريقة 2 — Android Studio:
1. افتح الملف ZIP في Android Studio
2. Build → Generate APK
